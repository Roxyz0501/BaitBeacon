# Bait Beacon

Roxyz0501 による独立した Dalamud プラグインです。GatherBuddy Reborn に保存された Auto-Gather リストを選び、リスト内の魚に必要な餌を表示します。所持品、チョコボかばん、リテイナーの対応画面では該当する餌の枠を強調表示します。

## 使い方

ゲーム内で `/baitbeacon` を実行し、保存済みリストを選択します。リスト画面または設定画面の「ハイライトを有効にする」で強調表示全体をオン／オフできます。設定画面には所持品・チョコボかばん・リテイナー別のスイッチもあります。Reborn の `auto_gather_lists.json` は読み取り専用です。Config で GatherBuddy Reborn と GatherBuddy の導入・読み込み状態を確認できます。

元の GatherBuddy には互換 Auto-Gather リストがないため、リストの読み込み対象は Reborn のみです。餌データのない魚は一覧で分けて表示します。

魚と餌の対応表は 2026-10-11 時点の上流全パッチのデータです。泳がせ釣りでは対象魚に明示された初期餌を優先し、指定がなければ泳がせ元の魚の餌をたどります。直感魚のために先に釣る魚の餌も対象です。銛漁の魚は餌が不要なので判定から除き、餌へたどれない釣り竿の魚だけを未登録として表示します。Reborn 側で利用者が追加した魚データの上書きは読み込みません。

## 言語

独立した「言語設定」タブで日本語、英語、ドイツ語、フランス語、韓国語、簡体字中国語、繁体字中国語を切り替えられます。初回だけゲーム言語、対応する Dalamud UI 言語、英語の順に決定して保存します。変更は再起動せず反映され、保存した選択を維持します。アイテム名はゲームが提供する言語データを使用し、韓国語・中国語では英語名になる場合があります。独立した「支援」タブは共通デザインを使用し、ボタンを押したときだけ Ko-fi を開きます。

## 設定保存と復旧

設定は画面へ即時反映し、60秒ごとに変更がある場合だけ保存します。ログアウト・正常終了・プラグイン無効化でも未保存分を保存します。既存の設定ファイルを使い、隣接する `.backups` ディレクトリへ正常な旧版を最大3世代保持します。破損した本体は別名で保持し、正常バックアップから復元します。強制終了では最後の正常保存以降、最大約60秒分の変更が失われる場合があります。

強調表示とリスト読込は3秒以上空けて再試行し、3回連続失敗すると対象処理を停止します。最後の正常なリストは保持します。リストの「再読み込み」、またはエラー表示の「再試行」で再開できます。設定保存の再試行は60秒間隔で3回まで、その後は停止します。終了時は同じ未保存内容に対し追加で1回だけ保存を試みます。起動時に設定ファイルを読み取れない場合は、明示再試行まで置換しません。リストファイルの上限は8 MiBです。取引履歴は記録しません。
